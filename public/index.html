Mandate speaks MCP. Point any MCP-capable agent (Claude Code, Claude Desktop via mcp-remote, your own) at this server and it can search and request purchases. Every request still goes through your mandate, and you still approve each one with PayPal here.

Tools: search_catalog, propose_purchase, get_mandate. Token is stored hashed; generating a new one revokes the old one.
